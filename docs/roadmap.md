# 로드맵

## 입력 형식 (ChatGPT Ending 출력)
`docs/chatgpt-ending-prompt.md`의 형식. 항목마다 네 줄:
- Q: 그 문장을 끌어낸 AI의 질문
- Me: 내가 실제로 한 말(틀린 그대로)
- Native: 원어민이 할 말 = 쉐도잉 대상
- Pattern: 재사용 가능한 일반형 2–5단어

파싱은 라벨 기반 규칙. "none — I didn't get stuck today." 는 빈 세션으로 저장(연속 일수에는 포함).

## 1. 붙여넣기 → 세트 저장
- 화면: 텍스트 영역 하나 + 저장 버튼. 붙여넣으면 미리보기로 항목 수 표시
- 저장 단위: 세션(날짜) → 항목(Q·Me·Native·Pattern·상태·다음 복습일)
- 저장소: SQLite(expo-sqlite)로 확정(2026-10-01). 3·4단계가 복습일·"다시" 횟수로 조회해야 해서. 표는 `sessions(date)`, `items(q, me, native, pattern, stage, due)`. `stage`는 간격 단계(0=1일), `due`는 다음 복습일(YYYY-MM-DD, 저장 다음 날로 시작). 녹음 파일은 FileSystem에 항목당 1개
- "저장한 세트" 탭: 저장한 세션을 최신순으로 보여준다(추가한 날짜, 문장 카드, 다음 복습일). 삭제·수정 없음
- 문장 카드에서 바로 Native 읽어주기(스피커 버튼)와 녹음·내 녹음 듣기 가능(2026-10-01 테오 요청으로 2단계에서 앞당김). 2단계 세션 화면은 이 읽어주기·녹음 코드를 그대로 쓰고, 순서 진행·횟수 카운트·됐다/다시만 더한다
- 구형식(`- "Me" → Native`)은 Q·Pattern을 공란으로 저장. Native가 없는 항목은 버린다

## 2. 세션 화면
- 오늘 복습할 항목만 큐로. 항목당 흐름: Q 재생 → Native 표시·재생 → 녹음(횟수 카운트, 목표 3–5) → 내 녹음 재생 → "됐다 / 다시"
- Me는 작은 글씨로 같이 표시(내가 이렇게 말했었다)
- 큐가 비면 "오늘 끝" 한 줄

## 3. 간격 반복과 알림
- 알림 시각과 복습 주기는 앱 안에서 테오가 직접 설정한다(2026-10-01 결정). 기본값만 정해 두고 설정 화면에서 바꾼다
- 주기의 숫자는 "저장한 날부터 며칠째"다(2026-10-01 결정). 예: 7·14면 저장 7일째와 14일째에 복습. 직전 복습부터의 간격이 아니다
- 주기 기본값은 1·3·7·14·28·60·120일(Claude가 정함, 테오 확답 없음). 테오 제안은 7·14·21·28·60·90·120일이었고 설정에서 그대로 입력하면 된다
- "됐다"면 다음 차례 날짜로(이미 지난 차례는 건너뜀), 마지막 차례를 통과하면 복습 완료. "다시"면 다음 날 한 번 더 나오고, 통과하면 원래 일정의 다음 날짜로 이어감(Claude가 정함, 테오 확답 없음)
- 설정한 시각에 그날 복습할 문장이 있으면 로컬 알림 1개. 없으면 알림 없음. 복습을 안 하면 문장이 남아 있으므로 다음 날에도 알림이 온다
- 알림을 누르면 복습 탭으로 진입
- 무료 개인 팀은 푸시 권한이 없어, expo-notifications가 자동으로 넣는 `aps-environment` 권한을 `plugins/withoutPushEntitlement.js`로 뺀다. 이 플러그인을 지우면 실기기 서명이 깨진다

## 4. 기록
- 연속 일수, 총 세트 수, "다시" 상위 패턴
- "다음 세션 패턴 3개" 버튼: 최근 2주에서 "다시"가 잦은 Pattern 3개를 복사

## 나중에
- 음성 인식으로 내 발음과 Native 비교
- ChatGPT 내보내기 파일 통째로 가져오기
- 스토어 출시, 다른 사용자

## 탈락·보류한 아이디어와 이유
- 웹(PWA): 아이폰 웹 푸시가 불안정하고 서버가 필요. 알림이 핵심이라 앱
- 서버·계정: 혼자 쓰는 동안 불필요. 기기 백업은 iCloud에 맡김
- 발음 점수: 판정이 틀리면 신뢰를 잃음. 듣고 말한 기록이 먼저
